# SondIA ERP

Herramienta interna de SondIA (Guzmán, Dani y Hugo): horas, tareas, LPs y OBVs, clientes y leads, y objetivos semanales.

- `PRODUCT.md`: contexto de producto.
- `DESIGN.md`: sistema de diseño (semilla de marca).
- `PROMPT.md`: el encargo original.
- `datos-iniciales/`: datos reales para el seed.
- `marca/`, `referencias/`: identidad y referencias de estructura.

Stack previsto: Next.js (App Router) + TypeScript + Tailwind + Supabase + Vercel.
